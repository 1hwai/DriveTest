# 휠·서스펜션 복구 — 조사 결과 및 해결 기록

> `WheelSuspensionRecoveryPlan.ko.md`의 대응 문서다. 이 문서는 별도의 아키텍처 명세가 아니라 계속 갱신하는 근거 기록이다.
>
> 단계별 조사 결과와 합의된 해결책을 기록한다. 확인되지 않은 내용을 추측으로 채우지 않는다. 영문 기록과 동기화한다.

## 기록 규칙

- 가능한 경우 정확한 파일 경로, 심볼, 줄 범위, 테스트 이름, 명령어, 커밋·리비전, 관련 출력을 기록한다.
- **관찰된 사실**, **해석**, **제안된 해결책**, **합의된 결정**을 구분한다.
- 문서에 제안이 적혀 있다는 이유만으로 구현 승인이 된 것은 아니다. 구현 전에 합의를 기록한다.
- 구현 상태와 검증 상태를 별도로 기록한다.
- 근거가 바뀌면 이전 결론을 조용히 지우지 말고 날짜·리비전이 있는 갱신 기록을 추가한다.
- 최신 검증 근거를 기록하기 전에는 해결 완료로 표시하지 않는다.
